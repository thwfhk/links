# SmallLinks

SmallLinks is a native subset of Links with modal effect types,
Fresco type inference, first-class polymorphism, record and variant
rows, linear types and algebraic effect handlers.

Build from source with `make`. Run `./links` for the REPL, pass
`-e` to evaluate an expression, or pass a source file to run it.
See [INSTALL.md](INSTALL.md) for dependencies and installation.

[Build the web demo](tasks/web/IMPL.md#build-and-serve) to try SmallLinks
with an editor, a grouped example catalogue, a source viewer and the
language guide.

Read the [language guide](tasks/met/GUIDE.md) for syntax and examples.
The [design specification](tasks/met/SPEC.md),
[implementation notes](tasks/met/IMPL.md) and
[milestones and checks](tasks/met/PLAN.md) describe the compiler work.
